dsh CLI not found

dsh-ui is a shell for the official DeepSeek Harness dsh command. It needs dsh installed and on your PATH to start the agent.

Install dsh

npm install -g @deepseek-ai/dsh

Verify

dsh --version

Then restart dsh-ui

Quit this window and reopen dsh-ui. It will find dsh and launch the agent.

Custom path

If dsh is installed somewhere exotic, set the DSH_BIN environment variable to the full path before launching dsh-ui.

Help / Feedback

Visit the dsh-ui GitHub repository for documentation, issues, and releases.
